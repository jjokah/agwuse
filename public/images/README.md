# Site imagery

Photos sourced from the previous production site (agwuse.org) via
`scripts/fetch-site-images.sh`. To replace any image, drop a new file with the
same name and similar aspect ratio. Larger and sharper originals are always
welcome, especially for the minister headshots.

| File | Used on | Notes |
|---|---|---|
| `hero/home-main.jpg` | Home hero | Landscape, at least 2000px wide |
| `sections/children.jpg` | Home ministries tile | Children's Sunday school |
| `sections/outreach.jpg` | Home welcome section | Portrait orientation |
| `sections/choir.jpg` | Home ministries tile | Choir or worship team |
| `sections/prayer-strip.jpg` | Prayer request page band | Very wide strip (about 4:1) |
| `sections/church-building.png` | Contact page | Building exterior; bottom of the image is cropped off in the layout |
| `ministers/*.jpg` | Ministers page | Square headshots, named per minister |
| `board/*.png` | Church board page | Square headshots, named per elder |
| `gallery/ag-wuse-01..12.jpg` | Gallery and section tiles | General congregation photos |
